# 5.5 极简全栈：FastAPI 与 SQLite 个人博客系统实战

> 🚧 **本节内容占位中（即将更新）**
> 
> 本节将带领大家利用 OpenCode 从 0 到 1 打造一个经典、通用且免复杂配置的传统轻量级全栈系统 —— **《极客个人博客与文章管理系统》**！
> 体验如何用自然语言意图驱动 AI 智能体同时编写 Python 后端 RESTful API、定义 SQLite 数据库模型与持久化存储、以及构建现代响应式前端交互页面！

---

## 🎯 核心实战目标（规划中）

1. **经典前后端 + 数据库架构**：
   - **后端（Backend）**：使用 FastAPI 构建标准的 RESTful API（文章列表、详情、发布、编辑、删除与阅读量计数）；
   - **数据库（Database）**：使用 Python 原生内置的 SQLite（无需安装额外数据库服务，单文件 `blog.db` 存储）；
   - **前端（Frontend）**：现代响应式单页（HTML5 + TailwindCSS + Markdown 实时解析渲染器）。
2. **完整 CRUD 全套闭环**：
   - 文章发布（Title, Category, Content, Status）；
   - 文章列表瀑布流卡片与分类标签筛选；
   - Markdown 文章阅读详情页与阅读次数自增；
   - 文章编辑修改与安全删除。
3. **OpenCode 全栈意图编排心流**：
   - 体验如何指挥 OpenCode 自动搭建后端服务、初始化 SQLite 表结构、编写前端页面并进行全链路联调。
