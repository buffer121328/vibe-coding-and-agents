## 🌐 一、前后端联调要点

1. **同源单页托管**：
   - 在 `main.py` 的根路径 `/` 直接返回 `index.html`：
   ```python

   def serve_spa():
       return FileResponse("index.html")
   ```

## 🛡️ 二、基础异常与功能自测

| 测试项 | 操作 | 预期结果 |
| :--- | :--- | :--- |
| **文章创建** | 填写标题与 Markdown 正文点击发布 | 列表立即新增卡片，数据库成功写入 |
| **详情与计数** | 点击卡片打开详情模态框 | Markdown 正确渲染，阅读量自增 1 |
| **文章编辑** | 点击编辑修改标题与内容后保存 | 列表与详情同步更新 |
| **文章删除** | 确认删除指定文章 | 列表卡片移除，数据库物理删除 |
| **分类筛选** | 点击分类胶囊标签 | 列表仅显示该分类下的文章 |
| **搜索过滤** | 输入关键词 | 列表即时过滤包含该词的文章 |
