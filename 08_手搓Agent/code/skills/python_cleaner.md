# Python 清洁工（教学技能包）

把这个文件扔进 `skills/`，Agent 写或改 Python 时才挂载。它教的是「怎么把代码写干净」，不是再发明一套框架。

## 什么时候用

用户提到重构、类型注解、注释、PEP 8、把脚本整理成可维护模块时启用。

## 必须遵守

1. **类型注解要写**：函数参数和返回值标出来；容器用 `list[str]`、`dict[str, int]` 这种写法。
2. **注释用中文，且只写代码自己说不清的约束**：参数含义、边界条件、为什么不能删这行。下一行在干什么不要再复述一遍。
3. **名字说人话**：`user_id` 而不是 `x`；布尔用 `is_` / `has_` 开头。
4. **先跑再吹**：改完用现成测试或最小自测证明没把原功能弄坏；没有测试就补一条能红能绿的。
5. **依赖要显式**：新库写进 `pyproject.toml`，不要默认「我机器上有」。

## 出手顺序

1. 读懂现有风格，跟着仓库走，不突然换一套命名。
2. 改最小必要范围，顺手清掉你碰到的死代码。
3. 告诉用户改了哪几处、为什么，而不是丢一块看不懂的 diff。
