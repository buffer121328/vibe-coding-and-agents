# 第十五章：Agent 开发面试题 —— 内功修炼才是真正的护城河

> 💡 **"面试题年年变，基本功不会变。Agent 开发岗位的面试官真正想确认的，不是你背过多少名词，而是：基本功扎不扎实，以及给你一个真实业务，你能不能把它扛起来。"**
>
> 关于 Agent 开发岗位，我还是劝大家专注**内功修炼**——概念和框架的保质期越来越短，两三个月就能速成的"框架调包能力"，恰恰是面试中最不值钱的部分。所以本章的面试题不按"背诵清单"整理，而是按岗位真实考察方式，分为八大基础模块加一个 Agent 综合专题。

***

## 🗂️ 八大模块总览

| 模块 | 考察本质 | 为什么 AI 时代还要考 |
| :--- | :--- | :--- |
| **Python 基础** | 语言机制与工程习惯 | Agent 代码终究是人审、人修、人兜底 |
| **计算机网络** | 请求的一生与故障定位 | Agent 全链路都是 HTTP/SSE/流式通信 |
| **数据结构** | 数据组织与复杂度直觉 | 选型即决策：队列、树、图的日常运用 |
| **操作系统** | 进程线程与资源调度 | 并发、阻塞、超时是 Agent 稳定性的命门 |
| **软件工程** | 协作、测试与交付质量 | 会不会 Review、能不能维护比会不会写更重要 |
| **数据库** | 存取、事务与性能账本 | 会话存档、记忆库、向量库都逃不开它 |
| **系统设计** | 权衡取舍与容量思维 | 从"能跑"到"能扛"的分水岭 |
| **Agent 专题** | 概念 + 框架 + **业务场景选型** | 岗位核心：给你一个业务，怎么快速搭起来 |

> 📌 **为什么前七个模块占这么大比重？** 因为 AI 把"写代码"的门槛打没了，面试官只能往更深的地方挖：你写的每一段 AI 生成代码，都要你签字负责——而签字的底气，就来自这些内功（呼应 [12.5 如何让自己不可替代](../12_如何做一个自己的项目/05_如何让自己不可替代.md)）。

***

## 🤖 Agent 专题特别说明

Agent 除了常见的概念和框架外，其实考察的更多是**业务场景的理解**：给你一个业务，你怎么选型、怎么快速搭建起来一个 Agent？

面试官的高频连环追问长这样：

1. **需求拆解**：这个业务的本质问题是什么？哪些环节值得上 Agent，哪些用规则引擎反而更稳？
2. **范式选型**：ReAct / Plan-and-Execute / 工作流编排，为什么选这个？（对照 [8.2](../08_手搓Agent/02_ReAct思考范式.md) 与 [8.3](../08_手搓Agent/03_Plan_and_Execute规划范式.md)）
3. **技术选型**：Prompt 工程 / RAG / 微调怎么选？用 LangChain、LangGraph 还是低代码平台（Dify / Coze）？（对照 [12.0 七维分水岭](../12_如何做一个自己的项目/00_什么是生产级Agent项目.md)）
4. **落地追问**：上下文超限怎么办？工具调用失败怎么办？权限与安全怎么守？Token 成本怎么算？效果怎么评估？
5. **压轴题**：Demo 跑通了，离生产级还差什么？

> 🎯 **答好这类题的秘诀**：不背答案，而是平时就按"问题 → 选型 → 取舍 → 验证"的方式做项目。每一步都留证据，面试时自然有话可讲。

1. **先修内功，再刷题目**：建议先完成 [08 手搓 Agent](../08_手搓Agent/README.md) 与 [12 做自己的项目](../12_如何做一个自己的项目/README.md)，面试题只是检验内功的体温计；
