## MODIFIED Requirements

### Requirement: 文章卡片网格展示
系统 SHALL 以网格布局展示文章卡片，每张卡片包含标题、分类、纯文本摘要、标签、浏览量与日期；**并新增点赞数与评论数徽标**；编辑/删除按钮仅管理员可见。

#### Scenario: 正常展示文章列表
- **WHEN** 存在已发布的文章
- **THEN** 以卡片网格形式展示，每张卡片显示标题、分类徽章、内容摘要（前100字符）、标签、浏览量、相对时间、**点赞数与评论数**

#### Scenario: 未登录不显示管理按钮
- **WHEN** 用户未登录浏览文章卡片
- **THEN** 卡片不显示编辑与删除按钮

#### Scenario: 管理员显示管理按钮
- **WHEN** admin 用户浏览文章卡片
- **THEN** 每张卡片显示编辑与删除按钮

#### Scenario: 空状态展示
- **WHEN** 没有任何文章
- **THEN** 显示友好的空状态提示；「写第一篇文章」按钮仅管理员可见

#### Scenario: 卡片悬浮效果
- **WHEN** 用户鼠标悬浮在文章卡片上
- **THEN** 卡片上浮并显示发光阴影效果

### Requirement: 顶部导航栏
系统 SHALL 提供固定的顶部导航栏，包含博客标题、文章/浏览统计、搜索输入框、登录区（登录按钮或用户名+退出）和「写文章」按钮；统计数字以**全量总数**（非当前页）为准。

#### Scenario: 页面加载后显示统计信息
- **WHEN** 用户打开博客首页
- **THEN** 导航栏显示文章总数（跨分页的 `total`）与总浏览量

#### Scenario: 实时搜索文章
- **WHEN** 用户在搜索框输入关键词
- **THEN** 文章列表即时过滤，仅显示标题或内容包含该关键词的文章，并回到第一页

#### Scenario: 未登录时显示登录按钮
- **WHEN** 用户未登录
- **THEN** 导航栏显示「登录」按钮，隐藏「写文章」按钮

#### Scenario: 管理员登录后显示写文章
- **WHEN** admin 用户登录后
- **THEN** 导航栏显示用户名与「退出」按钮，并显示「写文章」按钮

#### Scenario: 点击写文章按钮
- **WHEN** 管理员点击「✍️ 写文章」按钮
- **THEN** 弹出 Markdown 双栏编辑器模态框

## ADDED Requirements

### Requirement: 首页分页导航
系统 SHALL 在文章卡片网格下方提供分页导航控件（「上一页 / 第 x 页 / 下一页」），支持翻页浏览；切换分类或搜索时回到第一页；无更多页时相应按钮禁用。

#### Scenario: 翻页浏览
- **WHEN** 用户点击「下一页」
- **THEN** 加载并展示下一页文章卡片，页码指示同步更新

#### Scenario: 首页/末页禁用
- **WHEN** 用户位于第一页或最后一页
- **THEN** 相应的「上一页」或「下一页」按钮禁用

#### Scenario: 切换筛选回第一页
- **WHEN** 用户切换分类或输入搜索关键词
- **THEN** 分页重置到第一页并重新加载

### Requirement: 阅读器点赞按钮
系统 SHALL 在文章阅读器模态框中提供点赞按钮，展示当前点赞数与已点赞状态；点击后调用点赞/取消点赞接口并即时更新界面。

#### Scenario: 未登录点击点赞
- **WHEN** 未登录用户在阅读器中点击点赞按钮
- **THEN** 弹出登录模态框，不发起点赞请求

#### Scenario: 登录后点赞/取消
- **WHEN** 登录用户点击点赞按钮
- **THEN** 调用点赞（未点赞时）或取消点赞（已点赞时）接口，按钮状态（已点赞红色填充/未点赞描边）与点赞数即时更新

#### Scenario: 已点赞状态回显
- **WHEN** 登录用户打开一篇已点赞的文章
- **THEN** 点赞按钮显示为已点赞状态并显示最新点赞数

### Requirement: 楼层评论渲染
系统 SHALL 在文章阅读器内容下方渲染评论列表：评论按时间升序显示「N楼」编号、作者用户名、相对时间与内容；登录用户可发表评论；评论作者本人或 admin 可见删除按钮并可删除；未登录显示登录引导。

#### Scenario: 展示楼层评论
- **WHEN** 访客打开含评论的文章
- **THEN** 显示评论总数与评论列表，每条按「N楼」编号、作者、时间、内容展示

#### Scenario: 发表评论
- **WHEN** 登录用户在评论输入框提交内容
- **THEN** 评论列表刷新并显示新评论（含最新楼层号），评论总数同步更新

#### Scenario: 未登录发表评论引导
- **WHEN** 未登录用户查看评论区
- **THEN** 不显示输入框，改为「登录后参与评论」引导；点击后弹出登录框

#### Scenario: 删除评论
- **WHEN** 评论作者本人或 admin 点击评论的删除按钮并确认
- **THEN** 该评论被删除，列表与评论总数同步更新；非作者非 admin 不显示删除按钮

#### Scenario: 加载更多评论
- **WHEN** 评论总数超过当前已加载数量
- **THEN** 显示「加载更多评论」并可追加加载后续分页（楼层号按偏移累计）
