## 📦 Git 是什么？下载与安装（5 分钟上手）

### 什么是 Git？（一句话 + 三大特征）

**Git 是一个「分布式版本控制系统」**。大白话：它是你电脑上的一个“存档管家”，能把你写代码的每一次修改都记录下来，随时回退到任意历史版本，还能让多人并行协作不打架。

1. **版本存档（时光机）**：每个 `commit` 就是一个存档点，写崩了可以一键回档；
2. **分布式（人人都是完整仓库）**：每个协作者的电脑上都有完整的历史备份，不依赖单一服务器；
3. **分支协作（平行宇宙）**：大家各自开分支干活，最后合并，互不干扰。

> ⚠️ **注意区分**：**Git** 是装在本地电脑上的“版本管理软件”（离线工具）；**GitHub** 是全球最大的“代码托管网站”（在线平台）。两者是“引擎”和“4S 店”的关系——先装好 Git，再用 GitHub 做云端备份。

### Git 下载与安装

1. **进入官网下载**：打开 [git-scm.com](https://git-scm.com/downloads)，选择对应你系统的版本（Windows / macOS / Linux）；
2. **一键安装**：下载后一路点 “Next” 默认安装即可，无需改任何配置（macOS 也可用命令行安装：`brew install git`）；
3. **验证安装成功**：打开终端输入 `git --version`，能输出版本号就说明装好了：
   ```bash
   git --version   # 例如输出: git version 2.47.0
   ```
4. **设置你的“签名”**（提交代码时记录你是谁，只需设置一次）：
   ```bash
   git config --global user.name "你的名字"
   git config --global user.email "你的邮箱"
   ```

> 💡 完全不想碰命令行？直接跳到文末安装 **GitHub Desktop** 图形化客户端，全鼠标操作也能完成提交与推送。

## 🛠️ 日常最常用 Git 命令速查（一学就会）

### ① 克隆与拉取更新（把代码拿到本地 / 同步最新）

```bash
# 克隆别人的/自己的远程仓库到本地（第一次用）
git clone https://github.com/用户名/仓库名.git

# 拉取远程最新代码并自动合并（每天开工第一件事）
git pull

# 只下载远程更新但先不合并（想先看看差异再决定时用）
git fetch
```

> **`git fetch` vs `git pull`**：`fetch` 只把远程更新下载下来、不自动合并（先看看再说）；`pull` = `fetch` + 自动合并（一步到位）。新手先无脑用 `pull` 即可。

### ② 日常提交四连（改完代码的固定动作）

```bash
git status                        # 1. 查看当前哪些文件被改动了（红色 = 未暂存）
git add .                         # 2. 把所有改动装进暂存区（快递纸箱）
git commit -m "feat: 添加用户登录功能"  # 3. 存档打标（备注这次改了啥）
git push                          # 4. 推送到远程云端备份
git log --oneline                 # 额外：查看提交历史（时光机的存档列表）
```

### ③ 撤销与回退（新手最救命的三个操作）

```bash
# 场景1：改乱了，想放弃某个文件的修改，回到上一次提交的状态
git restore README.md

# 场景2：误 add 了不想提交的文件，把它从暂存区撤出来
git reset HEAD secret.py

# 场景3：想整体回退到某个历史版本（高危操作，谨慎使用）
git log --oneline              # 先找到目标版本的 commit 号
git reset --hard 3f2a9c1       # 强制回退到该版本（会丢弃此后的所有提交！）
```

> ⚠️ `git reset --hard` 是**高危命令**，会永久丢弃回退点之后的改动。不确定时，优先用 `git revert <commit>` 生成一个“反向提交”来安全撤销。

### ④ 分支操作速查（平行宇宙切换）

```bash
git branch              # 查看当前所有分支（* 号表示当前所在分支）
git switch -c feature   # 新建并切换到 feature 分支
git switch main         # 切换回 main 分支
git merge feature       # 把 feature 分支合并进当前分支
```

### ⑤ .gitignore：让某些文件永远不提交

新建 `.gitignore` 文件，把不想上传的内容写进去（每行一个模式）：

```bash
.env            # 密钥环境变量，千万不能传！（防盗刷）
node_modules/   # 依赖目录，太大了
*.log           # 日志文件
.DS_Store       # mac 系统垃圾文件
```

### ⑥ SSH 免密推送（配置一次，永久告别输密码）

HTTPS 每次 push 都要输用户名密码（甚至被要求绑卡/输凭据），改用 **SSH 密钥**一次配置、永久免密：

```bash
# 1. 生成密钥（一路回车即可）
ssh-keygen -t ed25519 -C "你的邮箱"

# 2. 查看公钥并复制（粘贴到 GitHub：Settings → SSH and GPG keys → New SSH key）
cat ~/.ssh/id_ed25519.pub

# 3. 测试连接是否成功
ssh -T git@github.com
```

> 💡 这套 SSH 免密配置，正好解决很多新手“每次 push 都要输入密码/凭据”的烦恼，一劳永逸。

## 🌪️ 核心概念与生活化实战场景

### 1. 分支（Branch）与合并冲突（Merge Conflict）

- **日常生活比喻**：
  - 你和小明要共同策划一份《日本旅游攻略》。为了不互相打扰，你俩各自复印了一份草稿（拉出各自的 **分支**）。
  - 你在第 10 行写上了“住东京希尔顿酒店”，小明在第 10 行写上了“住新宿民宿”。
  - 当你们要把两份草稿合并（**Merge**）成终稿时，Git 就会亮起红灯报警：**“发生冲突（Conflict）了！第 10 行你俩写的不一样，请人类自己商量决定留哪一个！”**
- **Git 冲突解决大白话**：
  - 打开冲突文件，你会看到这样的标记：
    ```markdown
    <<<<<<< HEAD (你的分支)
    住东京希尔顿酒店
    =======
    住新宿民宿
    >>>>>>> xiaoming-branch (小明的分支)
    ```
  - 你只要删掉不想要的文字和尖括号标记，保留正确的那个，保存并重新提交，冲突就完美化解了！

## 📝 GitHub 注册教程

1. **打开入口**：在浏览器输入官方地址 <https://github.com>；
2. **填写信息**：
   - 点击右上角 **“Sign up”**；
   - 依次输入你的常用邮箱（QQ/163/Gmail 均可）、设置包含字母+数字的高强度密码、输入唯一的用户名（Username）；
3. **真人拼图校验**：根据屏幕提示旋转动物或匹配数量完成验证；
4. **邮件验证码激活**：打开邮箱将 8 位数字验证码填入，直接进入 GitHub 控制台！

## 🚀 国内顺畅访问与 Git 代理加速

- **为什么有时候连不上 GitHub？**：因为 GitHub 服务器在海外，直连就像跨国平邮，容易出现拥堵或丢包。
- **代理的原理**：就像找了一家“海外代收转运公司”，你的电脑把请求发给本地代理中转，再由代理极速取回代码。

先说清楚两个容易混淆的概念：**“梯子”和“代理软件”其实是两回事**：

- **梯子（机场订阅）**：你**购买的网络订阅服务**，商家给你一串订阅链接和流量额度，可以比喻成“海外流量包”；
- **代理软件（客户端）**：你**装在本地电脑上的软件**（如 Clash），负责读取订阅节点、接管系统网络请求，并把请求转发到海外节点。

完整流程：你的请求 → 本地代理软件 → 转发到海外节点 → 海外网站处理 → 结果原路返回 → 显示在你屏幕上，来回消耗的就是“流量包”里的流量。

#### 常见代理软件推荐（按平台挑一款即可）

| 软件                  | 适用平台                    | 特点                           |
| :------------------ | :---------------------- | :--------------------------- |
| **Clash Verge Rev** | Windows / macOS / Linux | 目前最主流的分支，界面友好、支持订阅链接一键导入（首选） |
| **ClashX**          | macOS                   | macOS 老牌轻量客户端，简洁稳定           |
| **V2rayN**          | Windows                 | 经典老牌客户端，配置灵活、社区资料多           |
| **Stash**           | iOS                     | iPhone / iPad 常用，支持订阅与规则分流   |
| **Surge**           | iOS / macOS             | 功能强大、规则引擎优秀（付费）              |

> 💡 装上代理软件后，它一般会默认监听本地某个端口（Clash 默认 `7890`），配置好就能一键加速 GitHub。这里不提供配置教程，请自行查阅相关资料。
