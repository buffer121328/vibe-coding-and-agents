# Design

<!-- impeccable:design-schema 1 -->

## World

**航站楼里的那两块屏。** 一块是**纸面**（浅底，用来读：说明、表单、卡片、清单），一块是**航显板**（机场出港牌那种，用来扫：等宽数据列、信号灯、大字计数）。

它明确拒绝的东西：三栏同屏挤满、圆角卡片套卡片、灰底软阴影那套通用 dashboard；也拒绝了上一版自己用过的「纸票据」世界（米色纸、撕口、旋转印章）——那套符号的复古感和「青春活泼」是反着的。

**为什么是这个方向**：需求点名了「看板要像机场那种、大一点、科技一点」「不要暗黑」「整体青春活泼」。机场出港牌给了结构（等宽列 + 信号灯 + 大字计数），明亮天蓝给了情绪。

三条取舍：主色只给「可以动」的东西；三个信号灯的语义不许混用（中性计数用主色，不用红）；等宽只给数据。

## Type

- **中文与正文**：`Noto Sans SC`（400 / 500 / 700），系统栈兜底。
- **数据**：`Azeret Mono`（400 / 500 / 600）配 `font-variant-numeric: tabular-nums`，只给时间、编号、金额、航线、计数这类要对齐的东西。

固定 rem 级差（12 / 12.5 / 13.5 / 14 / 16 / 19 / 22 / 30px），不做流式缩放。看板行 13px、抬头大字 30px、时钟 19px。

## Layout

```
┌──────────┬──────────────────────────────────────────────┐
│ 旅行管家  │ 顶栏：页名 + 一句说明        模型/模式/会话   │
│──────────├──────────────────────────────────────────────┤
│ 对话      │                                              │
│ 行程  2段 │      当前页（一次只放一件事）                │
│ 探索 16城 │                                              │
│ 看板 78件 │  看板：抬头大字计数 + 筛选 + 等宽行表        │
│ 订单  2单 │                                              │
│ 运维      │                                              │
│──────────│                                              │
│ 旅客 xxx  │                                              │
│ 退出登录  │                                              │
└──────────┴──────────────────────────────────────────────┘
```

- 左栏 186px；≤1100px 收成图标栏；≤780px 变成横向图标条。
- 页面路由用 `#/board` 形式的锚点（与 DOM id 不冲突），刷新与返回键都能用。
- 卡片块（`.card-block` + `.block-head`）是内容容器；圆角 14px、一层薄影；列表行优先于卡片嵌套。

## Principles

1. **一页一件事**：分页承载「不同的事」，页签只承载「同一件事的切面」。
2. **状态用灯说**：圆点 = 有状态，橙 = 有人要签字，绿 = 落定，红 = 出事。
3. **读的归纸面，扫的归看板**：长文与表单在浅色卡上；数据、计数、状态在等宽列里。
4. **动效只回答「什么变了」**：看板行状态变化时闪一次（`.board-row` 的 `flip`），不做入场表演；`prefers-reduced-motion` 全关。
5. **控件用通行叫法**：登录 / 注册 / 退出登录 / 订单 / 看板 / 行程，不把机场比喻写进控件名。

## States

- 登录：错误条（`--no-bg` 底）、成功条（`--ok-bg` 底）、按钮 loading 文案、图形验证码「换一张」。
- 对话：流式回答、工具过程折叠（`执行中` / `已完成` / `未回执` 徽章）、审批闸门（琥珀底 + 批准/驳回）、SSE 断流的错误文案。
- 列表：空态一句「怎么开始」（起手卡 / 挑个城市 / 发一句话建对话），不用「暂无数据」。
- 看板：筛选后无结果给 `这个筛选下没有库存`；数据刷新只在状态真变的那行闪一次。
- 键盘：全局 `:focus-visible` 2px 主色描边；导航项与筛选按钮都是原生 `button`。
