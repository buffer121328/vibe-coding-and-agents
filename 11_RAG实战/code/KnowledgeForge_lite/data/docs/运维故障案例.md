# 运维故障案例库（节选）

## 案例 E3-2026-011：打印机报 E3 错误

**现象**：办公区打印机面板显示 E3，无法打印。
**原因**：进纸器卡纸，传感器未复位。
**处理步骤**：
1. 关闭电源，打开后盖取出卡纸；
2. 检查进纸传感器是否复位（拨杆回到水平位）；
3. 重新上电，若仍报 E3，联系行政部报修（内线 8100）。
**平均处理时长**：15 分钟。

## 案例 VPN-2026-044：VPN 连接后无法访问内网系统

**现象**：VPN 显示已连接，但打不开内部 OA。
**原因**：本地 DNS 缓存了旧的解析记录。
**处理步骤**：
1. 断开 VPN；
2. 执行 `ipconfig /flushdns`（macOS 为 `sudo dscacheutil -flushcache`）；
3. 重连 VPN 后再访问 OA。
**平均处理时长**：5 分钟。

## 案例 MAIL-2026-007：外部客户收不到我方邮件

**现象**：给外部域名发邮件被退信，提示 554。
**原因**：附件超过对方网关 25MB 限制。
**处理步骤**：改用企业网盘生成分享链接发送，附件超过 20MB 一律走网盘。
