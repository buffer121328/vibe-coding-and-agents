# Forge 智能知识库产品 FAQ

## Q1：Forge 支持哪些文档格式？

目前支持 Markdown、纯文本、Word（docx）与 PDF。扫描版 PDF 需要 OCR，社区版暂不支持，企业版可开通。

## Q2：知识库更新后多久生效？

文档重新上传并解析完成后，检索索引**实时生效**；已有的问答缓存会在索引变更后自动失效。

## Q3：检索结果可以标注出处吗？

可以。所有问答默认开启证据引用模式，答案中的 `[1] [2]` 编号可点击跳转到原文档对应段落。若知识库中没有可靠依据，系统会明确提示"资料不足"并支持转人工，而不是编造答案。

## Q4：免费版的额度是多少？

免费版每月 100 次问答、500 条文档切块。超出后可按量付费或升级团队版（每月 999 元起，含 10 个成员席位）。

## Q5：数据安全如何保障？

所有数据加密存储；企业版支持私有化部署，知识不出内网。系统对上传文档会做提示注入扫描，包含"忽略指令"类可疑内容的文档会被标记待人工审核。
