# 员工差旅管理制度（2026 修订版）

> 适用范围：全体正式员工及劳务派遣人员。本制度由行政部负责解释。

## 第一条 住宿标准

- 一线城市（北京、上海、广州、深圳）住宿标准为每人每天不超过 **500 元**；
- 二线城市住宿标准为每人每天不超过 **350 元**；
- 同城多人出差鼓励合住，合住时每人标准可上浮 20%。

## 第二条 餐饮与交通补贴

- 出差餐饮补贴为每人每天 **150 元**，无需提供发票；
- 市内交通费实报实销，单日上限 **100 元**；
- 往返交通按高铁二等座 / 经济舱标准报销，确需升舱须经部门总监审批。

## 第三条 报销流程

1. 差旅报销单须在返回工作地后 **5 个工作日内**提交 OA 系统；
2. 超期未提交的，需附部门总监签字的情况说明；
3. 报销款项在审核通过后 **10 个工作日内**原路发放至工资卡。

## 第四条 违规处理

虚报冒领差旅费用的，除全额追回外，视情节轻重给予警告直至解除劳动合同处理。
